# Visor 3D Interactivo - Mostrador de Recepción Comercial

Aplicación web 3D interactiva y paramétrica desarrollada con **Three.js** para visualización arquitectónica y despiece milimétrico de carpintería para un mostrador de recepción comercial moderno.

## 🚀 Características
- **Modelo 3D Paramétrico en tiempo real**:
  - **Largo**: 1600 mm a 3000 mm (recalcula automáticamente la cantidad y distribución de listones de roble).
  - **Alto**: 900 mm a 1300 mm (con mínimo ergonómico de 900 mm).
  - **Fondo / Ancho**: 550 mm a 950 mm.
- **Despiece Dinámico de Carpintería**:
  - Tabla de cortes milimétricos en tiempo real (Melamina 18mm, Melamina 36mm, Listones 30x30mm, Perfiles LED).
  - Exportación a archivo **CSV** para corte en taller.
- **Vista Explosionada (Despiece)**:
  - Control deslizante interactivo de 0% a 100% para ver cada componente separado.
- **Control de Capas (Marcar / Desmarcar)**:
  - Oculta o muestra partes específicas (Cubierta, Bastidor, Listones, LED, Cajones, etc.).
- **Optimizado para Móviles y Escritorio**:
  - Panel táctil inferior (Bottom Sheet) para teléfonos y controles multitáctiles (1 dedo rotar, 2 dedos zoom/paneo).

## 📦 Uso
Abre `index.html` en cualquier navegador web moderno (Chrome, Safari, Firefox, Edge). No requiere instalación de dependencias ni servidores externos.
